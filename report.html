Introduction

I focused on researching New Zealand’s Government communication about housing related topics from publications that were already issued by Government websites known as the Beehive. I used the keyword “housing” for my query and filtered the results to show only Labour Government issued content published in 2020 through to 2023. This produced over 60 returns. All the documents returned contained either Government Press releases or Speeches about different housing related topics that included Public Housing, Affordable Housing, Rental Issues, Flood Recovery Housing, and Housing Development Projects.

I decided to focus on housing because housing affordability and the cost of living have become very significant political and social issues within New Zealand. Housing impacts various areas of peoples lives, such as renting a home, owning a home, living standard, and the provision of safe and secure shelter. Therefore I wanted to explore how New Zealand’s Government communicated their housing priorities and themes during this time.

According to the Beehive website, information that is produced by the Crown and is protected by Copyright may be copied and used without cost, provided that the copied information is an accurate reproduction of the original material from the Beehive and that the Crown’s source is acknowledged. Copyright free information that has been modified in any way has not been authorised nor given permission for use by New Zealand’s Government. Furthermore, the Beehive website indicates that Government Logos, Trade Marks, Photographs, and/or Third Party Materials will not be used without the permission of the appropriate rights holder. In addition, the robots.txt file disallows automated scraping of the /search/ page, so the HTML pages for this project were saved manually before being analysed in R.

Visualisation

The purpose of my visualisation is to show the key themes being expressed by the Beehive in their Government releases regarding housing during the Labour Government period 2020-2023. I wanted to find out what issues about housing were mentioned most in communication by governments and what topics were highlighted in the search results.

I used text analysis with the packages {stringr} and {dplyr} to categorize the output from the Beehive as public housing, renting, affordability, building supply, climate/disaster housing, and energy efficient housing. This enabled me to structure unstructured text data into meaningful categories that were able to be clearly visualised.

The project also correlated Beehive search result information with data about the ministers from Wikipedia, which was obtained from Wikipedia’s API. The visualisation shows that during this period housing communication was dominated by construction(Building supply), disaster housing and renting and that the themes of affordability and public housing were represented less frequently.

Creativity

My visualisation shows creativity by using the function {stringr} for text analysis to create custom themes in the housing category from the search results of the Beehive search. I used the keywords from the titles and summaries to group each theme into categories, rather than the ones on the website, so that they were not grouped as the original categories.

I also linked Beehive search results data with data about the ministers from the Wikipedia API. This had to involve merging several digital data sources and cleaning of the text data prior to visualisation. I decided to use a horizontal bar chart, with housing themes reordered, and use colours to group them together so that the visual differences are more readily understandable and visible. The project merges together Web Scraping, API Data, Text Analysis, and Data Visualisation in one single workflow.

scrape_search_results <- function(page_path) {
  # Read HTML
  html_doc <- read_html(page_path)
  
  # Extract the isolated search result nodes (the individual cards)
  # This will depend on how you've acquired the results
  # Look for .search-result or .teaser (though there may be others)
  nodes <- html_doc %>% html_elements(".search-result")
  
  # Map over each individual search result
  map_df(nodes, function(node) {
    # Title
    title_element <- node %>% html_element("h2 a, h3 a, .views-field-title a")
    title <- title_element %>% html_text2()
    
    # Date and time
    date_element <- node %>% html_element("time, .views-field-created, .date")
    datetime  <- date_element %>% html_attr("datetime") # Raw timestamp
    date_text <- date_element %>% html_text2()          # Human-readable text
    
    # Summary
    summary <- node %>% html_element(".views-field-search-api-excerpt, .field-content, p") %>% html_text2()
    
    # Ministers
    minister <- node %>%
      html_elements("a[href*='/minister/']") %>%
      html_text2() %>%
      # trim out excess white space noise, and collapse them using a semicolon
      str_trim() %>%
      paste(collapse = ";")
    
    # Portfolios
    portfolio <- node %>%
      html_elements("a[href*='/portfolio/']") %>%
      html_text2() %>%
      # trim out excess white space noise, and collapse them using a semicolon
      str_trim() %>%
      paste(collapse = ";")
    
    # Combine individual results into a tidy tibble
    tibble(
      datetime   = datetime,
      date_text  = date_text,
      title      = title,
      ministers  = minister,
      portfolios = portfolio,
      summary    = summary
    )
  })
}

# Analysing housing themes in Beehive text
beehive_themes <- beehive %>%
  mutate(
    text = str_to_lower(str_c(title, summary, sep = " ")),
    theme = case_when(
      str_detect(text, "public housing|kāinga|kainga|community housing") ~ "Public housing",
      str_detect(text, "rent|rental|tenant|landlord|property manager") ~ "Renting",
      str_detect(text, "affordable|affordability|cost of living") ~ "Affordability",
      str_detect(text, "build|construction|development|homes|houses") ~ "Building supply",
      str_detect(text, "flood|cyclone|weather|resilience|recovery") ~ "Climate/disaster housing",
      str_detect(text, "energy|solar|renewable") ~ "Energy-efficient housing",
      TRUE ~ "Other housing"
    )
  )

# Combining Beehive data with Wikipedia minister data
minister_roles <- ministers %>%
  filter(label == "Political party") %>%
  distinct(minister, value)

combined_data <- beehive_themes %>%
  mutate(source = "Beehive") %>%
  left_join(minister_roles, by = character())

# Counting housing themes
theme_counts <- beehive_themes %>%
